Actividad 2:
Actividad para familiarizarse con pruebas unitarias con JUnit.
Esta actividad es solo un ejemplo y puede ser modificada y adaptada según las necesidades y conocimientos previos del estudiante.

El objetivo principal es aprender a escribir pruebas unitarias con JUnit, crear suites de prueba y automatizar la ejecución de pruebas con Jenkins.

HERRAMIENTAS NECESARIAS:
•	Un entorno de desarrollo Java (IDE)
•	Un servidor Jenkins instalado y configurado
•	Un repositorio de control de versiones (Git, por ejemplo)

INSTRUCCIONES:
1.	Familiarizarse con JUnit:
a.	Leer la documentación de JUnit en su sitio web y familiarizarse con sus conceptos básicos, como la estructura de un caso de prueba, las anotaciones, etc.
b.	Crear un proyecto Java en su IDE y agregar JUnit como dependencia.
c.	Escribir algunos casos de prueba simples para clases Java y asegurarse de que se ejecuten correctamente.
2.	Creación de un caso de pruebas con JUnit:
a.	Seleccionar una clase Java simple que se desee probar.
b.	Escribir varios casos de pruebas unitarias para esa clase, verificando diferentes escenarios de entrada y
salida.
3.	Creación de una suite de pruebas con JUnit:
a.	Seleccionar varios casos de prueba previamente escritos.
b.	Agrupar esos casos en una “suite” usando la anotación @RunWith y @SuiteClasses.
